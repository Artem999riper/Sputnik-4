# 🛰️ Спутник-Полевик ПК

Настольная версия Android-приложения «Спутник Полевик» для геологических полевых
работ. Работает на Node.js + браузер, запускается на `localhost:3100`.

## Запуск

```bash
cd Sputnik-Polevik-PC
npm install
node server.js
```

Открыть: <http://localhost:3100>

При первом запуске автоматически создаются `polevik.db` и `uploads/`.

## Возможности

Идентичны Android-приложению:

1. **Импорт справочников** (`refs.json`) — работники, транспорт, объекты, KML-точки.
   Файл выгружается из Спутника-4 (модуль «Полевые материалы» → «⬇️ Экспорт справочников»).
2. **Бригада** — состав работников + единица транспорта (привязывается к каждой
   завершённой скважине).
3. **Объекты → Объёмы → Скважины / Точки задач** — иерархия данных, объёмы трёх
   типов: бурение, статическое зондирование, термометрия.
4. **Редактор скважины** с пятью вкладками:
   - **Шапка** — название, дата, плановая глубина, диаметр, тип работ, координаты,
     геоморфология, описание.
   - **Слои + пробы** — массив слоёв (тип грунта, состояние, мерзлота, глубина);
     под каждым слоем — массив проб с типом отбора и упаковкой.
   - **УГВ** — массив отметок глубины грунтовых вод.
   - **ММГ** — массив диапазонов ММГ-пород.
   - **Фото** — четыре категории (Выработка, Бурение, Керн, Журнал) с лимитами
     2/5/5/4. Файлы укладываются в **подпапки `01_Фотофиксация_…/02_…/03_…`**
     внутри `uploads/<Объект>/<Скважина_дата>/` — конвенция Спутника-4.
5. **Финализация** скважины с валидацией (фото, глубина, слои).
6. **Импорт KML** — точки из .kml файла создаются как скважины или точки задач.
7. **Экспорт `.spk`** — архив, идентичный Android-выгрузке (`manifest.json`,
   `boreholes.json`, `soil_layers.json`, `samples.json`, `ugv.json`, `mmg.json`,
   `photos/<bh>_<cat>_<hash>.jpg`). Импортируется в Спутник-4 без изменений.
8. **Импорт `.spk`** — обратная совместимость: можно прочитать выгрузку из
   Android-приложения.
9. **Ведомости Excel** (пробы и объёмы) с настраиваемым форматом координат
   (WGS-84 десятичные / DMS / МСК-86 зоны 3 / 4). Стилистика повторяет
   ведомости Спутника-4.
10. **Сводка Word** за период по объёмам и скважинам.

Чего нет (по сравнению с Android):
- камеры — фото только загружаются.
- мобильного scoped-storage — все фото лежат в `uploads/`.

## Совместимость

- `.spk`, выгруженный из этой программы, импортируется в Спутник-4 ПК
  (`/api/field/preview-spk` → `/api/field/import-to-volume`) и в Android.
- `.spk` из Android-приложения можно загрузить через кнопку «📥 Импорт .spk» на
  странице экспорта.
- `refs.json` принимается ровно тот, что выдаёт Спутник-4 (`/api/field/refs/export`).

## Параллельная работа со Спутником

Программа использует порт **3100**, поэтому не конфликтует с основным
Спутником-4 (порт 3000). Можно запускать оба одновременно.

## Перенос в отдельный git-репозиторий

```bash
cp -r Sputnik-Polevik-PC ../Sputnik-Polevik-PC-standalone
cd ../Sputnik-Polevik-PC-standalone
rm -rf .git node_modules
git init
git remote add origin <ваш-новый-репозиторий>
git add -A && git commit -m "Initial commit"
git push -u origin main
```

## Технологии

- Node.js + Express
- better-sqlite3 (SQLite, WAL)
- multer (загрузка файлов)
- adm-zip (.spk архивы)
- docx (Word-сводка)
- proj4 (МСК-86 трансформации)
- xlsx-js-style на фронте через CDN
- Vanilla JS (без бандлера)

## Структура

```
routes/      — Express-маршруты по доменам
lib/         — утилиты (safe_folder, proj)
public/      — SPA (index.html + js/* + css)
uploads/     — фото скважин, разложенные по подпапкам
polevik.db   — SQLite-база
```
